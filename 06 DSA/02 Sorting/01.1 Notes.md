# 🔵 1. Bubble Sort

## 🔹 Core Concept

* Repeatedly **compare adjacent elements** and swap if they are in the wrong order.
* Largest element “bubbles up” to the end in each pass.

---

## 🔹 Pseudocode

```
for i = 0 to n-1:
    swapped = false
    for j = 0 to n-i-2:
        if arr[j] > arr[j+1]:
            swap(arr[j], arr[j+1])
            swapped = true
    if swapped == false:
        break
```

---

## 🔹 Implementations

### Python

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr
```

### Java

```java
public static void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n; i++) {
        boolean swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

---

## 🔹 Multiple Approaches

* Basic (no optimization) → always runs full loops
* Optimized → stop early if no swaps

---

## 🔹 Complexity

* Best: **O(n)** (already sorted)
* Worst: **O(n²)**
* Space: **O(1)**

---

## 🔹 Problem-Solving Strategy

* Rarely used in real problems
* Good for:

  * Detecting sorted arrays
  * Educational understanding

---

## 🔹 Real-Life Applications

* Teaching sorting basics
* Small datasets (rare)

---

## 🔹 Quick Tips

* Stable sort ✅
* Very slow ❌
* Easy to implement ✔️

# 🟢 2. Selection Sort

## 🔹 Core Concept

* Select **minimum element** from unsorted part and place it at correct position.

---

## 🔹 Pseudocode

```
for i = 0 to n-1:
    min_index = i
    for j = i+1 to n-1:
        if arr[j] < arr[min_index]:
            min_index = j
    swap(arr[i], arr[min_index])
```

---

## 🔹 Implementations

### Python

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

### Java

```java
public static void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        int temp = arr[i];
        arr[i] = arr[minIdx];
        arr[minIdx] = temp;
    }
}
```

---

## 🔹 Multiple Approaches

* Always same logic (no major optimization possible)
* Can reduce swaps (compared to Bubble Sort)

---

## 🔹 Complexity

* Best: **O(n²)**
* Worst: **O(n²)**
* Space: **O(1)**

---

## 🔹 Problem-Solving Strategy

* Use when:

  * Memory writes are costly
  * Need minimum swaps

---

## 🔹 Real-Life Applications

* Embedded systems (limited write operations)
* Small datasets

---

## 🔹 Quick Tips

* Not stable ❌
* Fewer swaps ✔️
* Predictable runtime ✔️

# 🟡 3. Insertion Sort

## 🔹 Core Concept

* Build sorted array **one element at a time**
* Insert element into correct position (like sorting cards)

---

## 🔹 Pseudocode

```
for i = 1 to n-1:
    key = arr[i]
    j = i - 1
    while j >= 0 and arr[j] > key:
        arr[j+1] = arr[j]
        j = j - 1
    arr[j+1] = key
```

---

## 🔹 Implementations

### Python

```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```

### Java

```java
public static void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

---

## 🔹 Multiple Approaches

* Standard shifting method
* Binary Insertion Sort (use binary search for position)

---

## 🔹 Complexity

* Best: **O(n)** (already sorted)
* Worst: **O(n²)**
* Space: **O(1)**

---

## 🔹 Problem-Solving Strategy

* Best for:

  * Nearly sorted arrays ⭐
  * Small inputs
* Often used inside:

  * Merge sort (for small chunks)
  * TimSort (Python’s sort)

---

## 🔹 Real-Life Applications

* Sorting playing cards
* Online sorting (data arriving continuously)
* Used in hybrid algorithms

---

## 🔹 Quick Tips

* Stable ✔️
* Fast for small data ✔️
* Adaptive ✔️ (improves with sorted data)

---

# ⚡ Final Comparison

| Algorithm      | Best Case | Worst Case | Stable | Key Feature            |
| -------------- | --------- | ---------- | ------ | ---------------------- |
| Bubble Sort    | O(n)      | O(n²)      | ✅      | Simple                 |
| Selection Sort | O(n²)     | O(n²)      | ❌      | Few swaps              |
| Insertion Sort | O(n)      | O(n²)      | ✅      | Best for nearly sorted |

---

# 🚀 When to Use What

* **Nearly sorted → Insertion Sort ✅**
* **Minimize swaps → Selection Sort**
* **Learning / debugging → Bubble Sort**
